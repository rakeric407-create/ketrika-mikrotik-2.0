Comment installer ?

💡 Le pack ZIP contient :

  • ketrika_LIC-XXXX.rsc — Fichier de config
  • LISEZ-MOI-INSTALLATION.txt — Tutoriel avec vos identifiants
  • COMMANDE-A-COPIER.txt — Commande prête à coller
1

📥 Téléchargez

Décompressez le ZIP sur votre PC.

2

📂 Glissez dans Winbox

Ouvrez Winbox → Files → glissez le .rsc

3

⚡ Collez la commande

New Terminal → collez depuis COMMANDE-A-COPIER.txt :

/import file-name=ketrika_LIC-XXXX.rsc

10-30 sec... Terminé ! ✅

💡 Astuce : renommer en k.rsc

/import file-name=k.rsc
